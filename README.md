# AI-logist — ИИ-агент для автоматизации логистики

Учебный проект по разработке ИИ-агента, способного взаимодействовать с логистической базой данных, находить клиентов и создавать заказы на перевозку с помощью Function Calling.

Проект демонстрирует интеграцию локальной языковой модели с Python-инструментами и SQLite.

## Цель проекта

Разработать ИИ-агента, который принимает запросы пользователя на естественном языке, определяет необходимые действия и вызывает соответствующие Python-функции для работы с логистическими данными.

## Реализованный функционал

- **Поиск клиентов** — поиск клиента по названию в базе данных.
- **Создание заказов** — регистрация заказа на перевозку с указанием клиента и города отправления.
- **Function Calling** — модель самостоятельно определяет, какой инструмент необходимо вызвать, и формирует аргументы.
- **Работа с SQLite** — хранение информации о клиентах и заказах.
- **Проверка данных** — проверка существования клиента перед созданием заказа.
- **Целостность данных** — использование внешнего ключа (`FOREIGN KEY`) для связи заказов с клиентами.
- **Обработка результатов** — передача результата выполнения Python-функции обратно языковой модели для формирования ответа пользователю.

## Примеры работы

**1. Поиск клиента**

Запрос:

```text
Найди клиента ООО Бета
```

Вызов инструмента:

```python
find_client(client_name="ООО Бета")
```

Результат:

```python
{
    "id": 2,
    "name": "ООО Бета",
    "email": "info@beta.ru"
}
```

**2. Создание заказа**

Запрос:

```text
Создай заказ на перевозку из Самары
для клиента с ID 1
```

Вызов инструмента:

```python
create_order(
    client_id=1,
    from_city="Самара"
)
```

Результат:

```python
{
    "success": True,
    "order_id": 4,
    "client_id": 1,
    "client_name": "ООО Альфа",
    "from_city": "Самара",
    "status": "created"
}
```

**3. Обработка некорректного запроса**

Если пользователь указывает несуществующего клиента, Python-функция отклоняет создание заказа и возвращает ошибку:

```python
{
    "success": False,
    "error": "client_not_found",
    "message": "Клиент с ID 999 не найден."
}
```

Заказ при этом не создаётся.

## Запуск проекта

**1. Установите Python и Ollama.**

**2. Загрузите модель:**

```powershell
ollama pull qwen2.5:3b
```

**3. Установите Python SDK:**

```powershell
pip install openai
```

**4. Запустите Ollama.**

Убедитесь, что локальный сервер доступен по адресу:

```text
http://localhost:11434/v1
```

**5. Запустите приложение:**

```powershell
python AI-agent.py
```

При запуске приложение инициализирует необходимые таблицы SQLite.

## Текущие ограничения

Проект находится в стадии разработки.

- Поддерживается один этап вызова инструмента в рамках одного пользовательского запроса.
- Последовательное выполнение нескольких инструментов пока не реализовано.
- Набор доступных операций ограничен поиском клиентов и созданием заказов.
- Используется локальная языковая модель с ограниченными возможностями по сравнению с более крупными моделями.
