AI-Логист — локальный AI-агент для автоматизации логистики

Локальный AI-агент для автоматизации операционных задач в логистике на Python + Ollama с поддержкой Tool / Function Calling.

Проект создаётся как практический пример применения LLM для автоматизации бизнес-процессов: агент самостоятельно определяет намерение пользователя, выбирает необходимый инструмент, формирует структурированные аргументы и получает данные из внешних источников.

🚧 Проект находится в активной разработке. Новые возможности и интеграции добавляются постепенно.

🧠 Что умеет проект

На текущем этапе AI-агент умеет:

принимать запрос пользователя на естественном языке;
анализировать намерение пользователя;
определять необходимость вызова инструмента;
выбирать подходящую функцию;
формировать аргументы функции в структурированном JSON;
вызывать внешний инструмент;
получать результат;
передавать результат обратно модели;
формировать итоговый ответ пользователю.
Пример

Пользователь:

Найди клиента ООО Альфа

AI-агент определяет необходимость вызова функции:

{
  "function": "find_client",
  "arguments": {
    "client_name": "ООО Альфа"
  }
}

Инструмент возвращает данные:

{
  "id": 1,
  "name": "ООО Альфа",
  "email": "info@alfa.ru"
}

После этого агент формирует понятный ответ пользователю.
