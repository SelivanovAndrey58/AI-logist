# AI-Логист — локальный AI-агент

Локальный AI-агент для автоматизации задач в логистике на **Python + Ollama** с поддержкой **Tool / Function Calling**.

> 🚧 Проект находится в активной разработке.

## 👋 Обо мне

Я начинающий **Python / AI Automation Developer** с 8-летним опытом работы в логистике.

Развиваюсь в направлении **AI-агентов, автоматизации бизнес-процессов и интеграции LLM с внешними системами**.

Моя цель — объединить практический опыт в бизнес-процессах с разработкой AI-решений.

## 🚀 Что умеет проект

AI-агент:

- принимает запрос пользователя на естественном языке;
- определяет необходимое действие;
- выбирает подходящий инструмент;
- формирует аргументы в JSON;
- вызывает функцию;
- получает результат;
- формирует ответ пользователю.

### Пример

**Запрос:**

> Найди клиента ООО Альфа

**AI → Function Calling:**

<pre>
{
  "function": "find_client",
  "arguments": {
    "client_name": "ООО Альфа"
  }
}
</pre>

**Результат:**

<pre>
{
  "id": 1,
  "name": "ООО Альфа",
  "email": "info@alfa.ru"
}
</pre>
